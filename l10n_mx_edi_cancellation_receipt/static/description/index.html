Gestión de Acuses de Cancelación SAT (CFDI 4.0)

Este módulo extiende las capacidades de la localización mexicana de Odoo para garantizar el cumplimiento fiscal estricto mediante el resguardo automático del Acuse de Cancelación (PDF y XML) emitido por el SAT.

📄 Contexto Fiscal y Normativa

La cancelación de un CFDI no es solo un proceso administrativo, es una obligación fiscal crítica. Como se establece en las regulaciones del SAT y las mejores prácticas para Odoo Enterprise (v19.0+):

  • Validez Fiscal: Cancelar una factura anula su existencia legal.
  • Plazos: La cancelación debe realizarse a más tardar el 31 de enero del año siguiente a su emisión.
  • Evidencia: Es indispensable contar con el acuse oficial que certifique que el folio fiscal (UUID) ha sido cancelado correctamente en los servidores del SAT.

🚀 Características Principales

  • Descarga del PDF y XML de Acuse: Al procesar una cancelación exitosa, el módulo recupera el XML de respuesta del PAC/SAT.
  • Adjunto Automático: El acuse se adjunta automáticamente al registro de la factura (Account Move) en el chatter para fácil auditoría.
  • Validación de Estado: Confirma visualmente que el estado del CFDI en el SAT es "Cancelado".
  • Actualización de Estado: Regenera el acuse al detectar rechazo, aceptación o vencimiento de plazo.

🛠 Gestión de Motivos de Cancelación (SAT)

Este módulo se alinea con el flujo estándar de Odoo para manejar los 4 motivos obligatorios de cancelación, asegurando que el acuse generado corresponda a la justificación correcta:

1. Motivo 01 - Comprobante emitido con errores con relación

  • Ideal para cuando existen errores en la factura (RFC, precios, etc.) y se requiere sustituirla.
  • Flujo soportado: El módulo permite vincular el acuse a la factura original y rastrear el UUID de la factura que la sustituye.

2. Motivo 02 - Comprobante emitido con errores sin relación

  • Para errores donde no se requiere relacionar una nueva factura inmediatamente (ej. error en datos que no afectan importes directos o re-facturación posterior).

3. Motivo 03 - No se llevó a cabo la operación

  • Cuando la venta se cae o el servicio no se presta.

4. Motivo 04 - Operación nominativa relacionada en una factura global

  • Para correcciones específicas en facturas de público en general.

📋 ¿Por qué usar este módulo?

Aunque Odoo gestiona la solicitud de cancelación, las empresas mexicanas requieren tener el archivo físico (PDF y XML) del acuse para responder ante auditorías o compulsas. Este módulo automatiza ese paso, evitando tener que entrar al portal del SAT para descargar los comprobantes manualmente.
